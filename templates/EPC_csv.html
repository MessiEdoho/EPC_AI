Basic instruction

Input
Please upload a CSV file which contains two-channel EEGs recorded during the status epilepticus period of intra-amygdala microinjection of kainic acid model of drug-resistant epilepsy in mice. The file must have two EEG columns, optionally after an index or time column, with or without a header row: first the ipsilateral channel (injection side), then the contralateral. EPC-AI accepts recordings sampled at {{ fs }} Hz only.

Output
The web page will return to you with an evaluation indicating whether the EEG is more likely to exhibit normal or outlier epilepsy phenotype. Additionally, the web server offers example EEG traces from status epilepticus periods, along with the features used for prediction.

Enter the sampling frequency, choose the signal unit, upload your CSV file (up to {{ max_mb }} MB) and click the "Epilepsy Phenotypes Classification" button. A new page will open when your results are ready. Please click Help for more details.
