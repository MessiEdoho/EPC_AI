Basic instruction

Input
Please upload an EDF file which contains two-channel EEGs, sampled at 500 Hz, recorded during the status epilepticus period of intra-amygdala microinjection of kainic acid model of drug-resistant epilepsy in mice. The first channel should be the ipsilateral electrode (injection side) and the second the contralateral. If the file contains more than two channels, you will be asked to choose the two EEG channels to use.

Output
The web page will return to you with an evaluation indicating whether the EEG is more likely to exhibit normal or outlier epilepsy phenotype. Additionally, the web server offers example EEG traces from status epilepticus periods, along with the features used for prediction.

Upload your EDF file (up to {{ max_mb }} MB) and click the "Epilepsy Phenotypes Classification" button. A new page will open when your results are ready. Please click Help for more details.
