EPC-AI EDF

Basic instruction

Input

Please upload an EDF file which contains two-channel EEGs recorded during the status epilepticus period of Intra-amygdala microinjection of kainic acid model of drug-resistant epilepsy in mice.

Output

The web page will return to you with an evaluation indicating whether the EEG is more likely to exhibit normal or outlier epilepsy phenotype. Additionally, the web server offers example EEG traces from status epilepticus periods, along with the features used for prediction.

Upload your EDF file and click the "Epilepsy Phenotypes Classification" button. A new page will open when your results are ready. Please click "Help" for more details.
